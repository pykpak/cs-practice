Рабочая папка — папка на компьютере, где я редактирую файлы проекта.



Индекс — промежуточная область, куда я добавляю файлы перед коммитом

командой git add.



Коммит — сохранённый снимок проекта с уникальным хешем, автором, датой

и сообщением. Точка, к которой можно вернуться.



Различия Git и GitHub



Git — это программа для контроля версий, которая работает локально

на моём компьютере. Она отслеживает изменения файлов.



GitHub — это онлайн-платформа для хранения репозиториев Git.

Это облачный сервис, куда можно отправить свой локальный репозиторий,

чтобы работать с ним с разных устройств или вместе с другими людьми.



Использованные команды



git status — показывает текущее состояние: какие файлы изменены,

какие добавлены в индекс, какие еще не отслеживаются.



git diff — показывает разницу между рабочей папкой и индексом

(что изменено, но еще не добавлено в индекс).



git diff --staged — показывает разницу между индексом и последним

коммитом (что уже готово к коммиту).



Ветки



Ветка — это отдельная линия разработки в репозитории. Она позволяет

делать изменения, не затрагивая основную ветку main.



При новом коммите в ветке указатель ветки сдвигается вперед на этот

коммит. Другие ветки при этом не меняются.



Слияние (merge) — это объединение изменений из одной ветки в другую.

При слиянии создается коммит слияния, в котором фиксируется результат

объединения двух линий разработки.
