## 1. Файл `stats.py` — Логика обработки данных

**Функция `parse_record(line)`** — разбирает одну строку.
* `parts = line.split(";")` — разбивает строку по точке с запятой на список из кусочков.
* `if len(parts) != 3:` — проверяет, что кусочков ровно 3. Если больше или меньше — прерывает работу.
* `raise ValueError(...)` — команда «выбросить ошибку». Мы используем её, чтобы сообщить, что строка плохая.
* `city, temp_str, date = parts` — распаковывает список из 3 элементов в 3 переменные.
* `if not city or not date:` — проверяет, что город и дата не являются пустыми строками.
* `try: temp = float(temp_str)` — пытается превратить текст в число с плавающей точкой (дробное).
* `except ValueError: raise ValueError(...)` — если превратить в число не удалось (например, написано «н/д»), 
  мы перехватываем системную ошибку и выбрасываем свою, с понятным текстом.
* `return {"city": city, "temp": temp, "date": date}` — возвращает результат в виде словаря (dict), как требует задание.

**Функция `read_valid(lines)`** — фильтрует список строк.
* `valid_records = []` — создает пустой список, куда мы будем складывать хорошие записи.
* `for line in lines:` — запускает цикл, проходя по каждой строке из входного списка.
* `if not line.strip(): continue` — `strip()` убирает пробелы по краям. Если после этого строка пустая, 
  команда `continue` перепрыгивает на следующую строку (пропускает пустую молча).
* `try: record = parse_record(line)` — пытается разобрать строку.
* `valid_records.append(record)` — если разбор прошел успешно, добавляет словарь в список хороших записей.
* `except ValueError: pass` — если `parse_record` выдала ошибку, мы ее ловим. Команда `pass` означает 
  «ничего не делать», то есть мы просто идем дальше (пропускаем плохую строку).
* `return valid_records` — возвращает список только с хорошими данными.

**Функция `average_by_city(records)`** — считает среднее.
* `totals = {}` и `counts = {}` — создают пустые словари для суммы температур и количества записей.
* `totals.get(city, 0.0) + temp` — метод `get` берет текущую сумму для города. Если города еще нет в словаре, 
  он берет `0.0` и прибавляет новую температуру.
* `averages[city] = round(totals[city] / counts[city], 1)` — делит сумму на количество и функция `round` 
  округляет результат до 1 знака после запятой.
* `return averages` — возвращает словарь вида `{"Город": средняя_температура}`.

**Функция `warmest_city(records)`** — ищет победителя.
* `averages = average_by_city(records)` — сначала вызывает предыдущую функцию, чтобы получить средние.
* `sorted_cities = sorted(averages.keys())` — берет все названия городов и сортирует их по алфавиту. 
  Это нужно, чтобы при равной температуре победил тот, кто первый по алфавиту.
* `best_city = sorted_cities[0]` — берет первый город из списка как временного победителя.
* `for city in sorted_cities[1:]:` — перебирает остальные города (срез `[1:]` пропускает первый).
* `if averages[city] > best_temp:` — если температура текущего города строго больше, он становится новым победителем.

## 2. Файл `main.py` — Интерфейс и запуск

* `import sys` — подключает модуль для работы с системным вводом/выводом.
* `from stats import ...` — импортирует нужные функции из нашего первого файла.
* `lines = sys.stdin.read().splitlines()` — читает весь текст, который подали на вход, и разбивает его на список строк.
* `records = read_valid(lines)` — передает все строки в функцию фильтрации и получает список чистых словарей.
* `non_empty = sum(1 for l in lines if l.strip())` — это генератор. Он проходит по всем строкам, 
  проверяет, что они не пустые, и функция `sum` считает их количество.
* `print(len(records))` — `len` считает количество элементов в списке. Печатает, сколько записей успешно разобрано.
* `print(non_empty - len(records))` — вычисляет, сколько строк было пропущено (из непустых вычитаем успешные).
* `if records:` — проверка на пустоту. Если валидных записей нет, код внутри блока не выполнится, и программа не упадет.
* `city = warmest_city(records)` — вызывает функцию поиска самого теплого города и сохраняет его имя.
* `average_by_city(records)[city]` — вызывает функцию средних и берет из полученного словаря значение по ключу `city`.
* `print(f"{...:.1f}")` — f-строка. Фигурные скобки подставляют значение переменной, а `:.1f` означает 
  «форматировать как число с плавающей точкой, 1 знак после запятой».
